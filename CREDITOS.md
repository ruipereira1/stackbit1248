### Sistema Stackbit 1248

Todas as informações sobre o sistema de codificação **1248** utilizadas nesta aplicação foram baseadas no conteúdo e documentação disponível no site oficial da Stackbit Metalwallet.

O sistema Stackbit 1248 é um método de codificação de palavras BIP39 usando um sistema de quadrados numerados (1, 2, 4, 8) para representar dígitos decimais de forma visual e física, permitindo que seed phrases sejam armazenadas de forma segura em metal.

### Sobre Este Projeto

Este projeto é uma **implementação web open source** do sistema Stackbit 1248, desenvolvida para:
- Facilitar o uso do sistema 1248 de forma digital
- Permitir codificação e decodificação de palavras BIP39
- Funcionar 100% offline para máxima segurança
- Ser uma ferramenta educacional e de referência
