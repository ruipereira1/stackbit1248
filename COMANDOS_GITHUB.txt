PRIMEIRO: Instalar Git
───────────────────────────────────────────────────────────────
1. Baixe: https://git-scm.com/download/win
2. Instale o Git
3. Reinicie o PowerShell

OU use winget (Windows 11):
  winget install --id Git.Git -e --source winget


DEPOIS: Execute os comandos abaixo
───────────────────────────────────────────────────────────────

# 1. Navegar para a pasta
cd c:\Users\ruiva\Desktop\seedsigner

# 2. Configurar Git (primeira vez apenas)
git config --global user.name "Seu Nome"
git config --global user.email "seu.email@exemplo.com"

# 3. Inicializar repositório
git init

# 4. Adicionar todos os arquivos
git add .

# 5. Fazer commit
git commit -m "Initial commit: Stackbit 1248 - Ferramenta BIP39 Open Source"

# 6. Renomear branch para main
git branch -M main

# 7. Adicionar repositório remoto
git remote add origin https://github.com/ruipereira1/stackbit1248.git

# 8. Fazer push (vai pedir autenticação)
git push -u origin main


AUTENTICAÇÃO:
───────────────────────────────────────────────────────────────
Quando pedir senha, use um TOKEN DE ACESSO PESSOAL:

1. Acesse: https://github.com/settings/tokens
2. Clique em "Generate new token" → "Generate new token (classic)"
3. Marque a opção "repo"
4. Clique em "Generate token"
5. COPIE o token (você só verá uma vez!)
6. Use o token como senha quando o Git pedir


OU USE O SCRIPT AUTOMÁTICO:
───────────────────────────────────────────────────────────────
Depois de instalar o Git, execute:
  .\publicar-agora.ps1
