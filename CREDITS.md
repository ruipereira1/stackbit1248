### Stackbit 1248 system

All information about the **1248** encoding system used in this app is based on content and documentation available on the official Stackbit Metalwallet website.

The Stackbit 1248 system encodes BIP39 words using numbered squares (1, 2, 4, 8) to represent decimal digits visually and physically, allowing seed phrases to be stored securely on metal.

### About this project

This project is an **open-source web implementation** of Stackbit 1248, built to:

- Make the 1248 system easier to use digitally
- Encode and decode BIP39 words
- Work 100% offline for maximum security
- Serve as an educational and reference tool
